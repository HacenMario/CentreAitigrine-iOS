# مركز أيت تقرين — تطبيق iOS الأصلي

التطبيق الرسمي لموقع **مركز أيت تقرين** للعناية النفسية والأرتفونية والتكوين:
**https://centreaitigrine.com**

- معرّف الحزمة: `com.aittegrine.center` — مطابق لتطبيق أندرويد المعتمد
- الاسم المعروض: **مركز أيت تقرين**
- الإصدار: **1.0.0 (build 1)** — يعمل مباشرة مع الموقع المنشور (المرجع: نسخة الويب v3.22.3)
- حد أدنى مدعوم: **iOS 15** — آيفون وآيباد
- اللغة الأساسية: العربية (مع ترجمات واجهة التطبيق الأصلية: عربية، فرنسية، إنجليزية، تركية، إسبانية)

---

## 1) ماذا يفعل التطبيق؟

نفس تجربة الموقع كاملة داخل تطبيق أصلي سريع، مع كل ما طُلب في تطبيق أندرويد المعتمد v1.1.0 وبإضافات خاصة بأجهزة آبل:

| الميزة | التفصيل |
| --- | --- |
| عرض الموقع كاملاً | WKWebView بجلسة دائمة: الولوج (توكن/كوكيز) يبقى محفوظاً بين الإطلاقات |
| شريط تقدم | شريط أخضر رفيع بأعلى الشاشة يتبع تحميل الصفحة |
| سحب للتحديث | اسحب الصفحة للأسفل لتحديثها — كسلوك التطبيقات الأصلية |
| الرجوع | إيماءة السحب من الحافة تعمل، مع دعم كامل لرجوع/تقدم الموقع |
| شاشة عدم الاتصال | تظهر تلقائياً عند انقطاع الشبكة، مع زر «إعادة المحاولة» وإعادة ولوج **تلقائية** فور عودة الشبكة |
| الروابط الخارجية | الهاتف `tel:` والبريد `mailto:` وواتساب `whatsapp:` والخرائط تفتح بتطبيقاتها، وأي نطاق خارج المركز (بوابات الدفع مثلاً) يفتح في سفاري |
| رفع الملفات | منتقي ملفات النظام الأصلي يعمل داخل الموقع، مع دعم الكاميرا والميكروفون عند طلب الصفحة |
| الموقع الجغرافي | إذن «أثناء الاستعمال» عند طلب الصفحة |
| الإشعارات الأصلية | إشعارات iOS أصلية لإشعارات الموقع الجديدة غير المقروءة (انظر القسم 6) |
| شارة الأيقونة | عدد الإشعارات غير المقروءة يظهر فوق أيقونة التطبيق |
| الاتجاهات | رأسي/أفقي على الآيفون، والآيباد بأربع اتجاهات |
| الهوية | ألوان وأيقونة مطابقة تماماً لتطبيق أندرويد المعتمد (`#007D65` والشعار الدائري الأخضر) |

## 3) المتطلبات

**للبناء على Mac (الطريقة الأولى):**
- macOS 13 Ventura أو أحدث
- Xcode 15 أو أحدث (مجاني من App Store)
- لتجربة التطبيق على هاتفك: حساب Apple ID مجاني (التثبيت الشخصي لمدة 7 أيام)
- للنشر على App Store/TestFlight: حساب **Apple Developer Program** (99$ سنوياً)

**للبناء بلا Mac (الطريقة الثانية):**
- حساب GitHub مجاني فقط — يبنى التطبيق على مستضيف macOS يوفره GitHub
- (التوقيع والنشر يحتاجان حساب Apple Developer في كل الأحوال — لا يوجد بديل عنه)

## 4) الطريقة الأولى: البناء على Mac بـ Xcode

1. انسخ مجلد `CentreAitigrine-iOS` إلى الماك وافتح `CentreAitigrine.xcodeproj` (نقرة مزدوجة).
2. من الشجرة يساراً اختر **CentreAitigrine** ثم التبويب **Signing & Capabilities**:
   - علّم **Automatically manage signing**
   - في **Team** اختر حسابك (Personal Team يكفي للتجربة على هاتفك)
3. وصّل الآيفون بالكابل، وفعّل «وضع المطوّر» إن طُلب (الإعدادات ← الخصوصية والأمان).
4. اختر جهازك من قائمة الأجهزة أعلى النافذة ثم اضغط **▶ Run**.
5. أول تشغيل على الجهاز: الإعدادات ← عام ← إدارة VPN والأجهزة ← اثق بحسابك.

**للحصول على IPA موقّع للتوزيع:**

```bash
xcodebuild -project CentreAitigrine.xcodeproj \
  -scheme CentreAitigrine -configuration Release \
  -allowProvisioningUpdates -derivedDataPath build archive

xcodebuild -exportArchive \
  -archivePath build/CentreAitigrine.xcarchive \
  -exportPath ./out \
  -exportOptionsPlist exportOptions.plist
```

> عدّل `teamID` داخل `exportOptions.plist` بمعرّف فريقك قبل أمر التصدير
> (تجده في developer.apple.com/account تحت Membership details).

## 5) الطريقة الثانية: بناء IPA عبر GitHub Actions بلا Mac

1. ارفع مجلد `CentreAitigrine-iOS` إلى مستودع GitHub جديد.
2. من تبويب **Actions** في المستودع اختر سير العمل **iOS Build** ثم **Run workflow**.
3. بعد اكتمال البناء (دقيقتان تقريباً) نزّل الـ Artifact باسم
   `CentreAitigrine-unsigned-ipa` — وهو ملف `CentreAitigrine-unsigned.ipa`.

**ملاحظات مهمة حول التوقيع:**
- الـ IPA الناتج **غير موقّع**: يصلح للفحص والقياس، ولا يثبت على الآيفون مباشرة.
- لتثبيته على جهاز يجب إعادة التوقيع بأحد هذه السبل:
  - **TestFlight (الأنسب)**: ابنِ نسخة موقّعة على Mac أو أعد التوقيع أدناه، ثم ارفعها.
  - إعادة توقيع سريعة بأداة مثل `p12` + ملف تعريف توفير:
    ```bash
    codesign -f -s "اسم شهادتك" --entitlements ent.plist Payload/CentreAitigrine.app
    zip -r signed.ipa Payload
    ```
  - أو خدما إعادة توقيع موثوقة (بشرط عدم رفع بيانات توقيعك لجهة غير موثوقة).

## 6) الإشعارات الأصلية — كيف تعمل وحدودها

نفس منطق أندرويد المعتمد (Poller.java) بنفس التوكن ونفس الواجهة:

1. بعد ولوجك داخل التطبيق، يستخرج التطبيق توكن الجلسة (من `localStorage.ait_token`).
2. كل **4 دقائق** وأنت داخل التطبيق، وخلفياً عند السماح به iOS (~15 دقيقة)، يستدعي
   `GET /api/notifications` برأس `x-auth-token`.
3. كل إشعار جديد غير مقروء يظهر إشعاراً أصلياً بعنوانه ونصه **بلغة جهازك**
   (من حقول `titles` و`bodies` متعددة اللغات) ويُحدَّث عدّاد الشارة.

**فرق مقصود عن أندرويد (طبيعة iOS):** أندرويد يملك خدمة خلفية دائمة ونبض منبّه كل
4 دقائق حتى مع إغلاق التطبيق. آبل لا تسمح بهذا المفهوم أصلاً؛ البديل المعتمد هنا هو
BGAppRefresh/background fetch ويقرر النظام توقيته. **الإشعار الأدق فوراً حتى والتطبيق
مغلق يتطلب APNs من الخادم مستقبلاً** — بنية التطبيق جاهزة له دون أي تغيير في الواجهة
(يُضاف `UNNotificationServiceExtension` وشهادة الخادم فقط).

## 7) النشر على App Store — قائمة تحقق

1. **حساب Apple Developer** مفعل (99$/سنة).
2. أنشئ App ID صريحاً باسم `com.aittegrine.center` (لوحة developer.apple.com) — أو اتركه Wildcard عند أول توقيع.
3. اختر أي ما يلي إن أردت تغييره **قبل** البناء النهائي: الإصدار في Xcode (Signing & Capabilities) أو في pbxproj (`MARKETING_VERSION`).
4. **App Store Connect** ← My Apps ← «+» جديد:
   - الاسم: مركز أيت تقرين (أو Centre Ait Tigrine للنسخة الفرنسية)
   - الفئة المقترحة: **Health & Fitness** أو **Medical**
   - سياسة الخصوصية: ضع رابط صفحة سياسة الخصوصية في الموقع نفسه
   - **حساب تجريبي للمراجع**: أنشئ حساباً على الموقع (اسم مستخدم + كلمة مرور) واكتبهما
     في خانة «Sign-in required» — مراجعو آبل يفتحون التطبيق ويعطون الإشعارات، والمراجعة
     تفشل غالباً بدون حساب جاهز.
   - لقطات الشاشة: 6.7 بوصة (آيفون) + 12.9 بوصة (آيباد) — يكفي التقاطها من المحاكي.
5. ملاحظة المراجعة (Review Notes) المقترحة:
   > «تطبيق مركز آيت تقرين يعرض موقع المركز الرسمي بحجز المواعيد والتكوينات، مع
   > إشعارات أصلية ورفع ملفات وشاشة عدم اتصال. للتجربة استعمل الحساب التجريبي المرفق.»
6. الإشراف على سؤال التشفير: الإجابة «لا» (مضبوطة مسبقاً في Info.plist عبر
   `ITSAppUsesNonExemptEncryption = false`).
7. بعد الموافقة: TestFlight للمستخدمين المبدئيين، ثم الإصدار العام.

**ملاحظة عن دليل المراجعة 4.2 (الحد الأدنى من الوظائف):** التطبيق ليس غلافاً صامتاً
للموقع — يضيف إشعارات iOS أصلية وشارة عدّاداً وسحب-للتحديث وشاشة عدم اتصال مع
إعادة ولوج تلقائي ورفع ملفات أصلياً وأذونات كاميرا/موقع معربة وواجهة بخمس لغات.
هذا غالباً كافٍ لتطبيق مؤسسة يعرض خدماتها؛ إن واجهت رفضاً بأسباب 4.2 فالخطوة
المعتادة هي إضافة تبويب أصلي بسيط (مثلاً «اتصل بنا») — أخبرني وسأضيفه فوراً.

| ألوان الهوية | `App/Theme.swift` | `primary` = أخضر المركز |

## 9) ملاحظات تقنية

- **أمان النقل (ATS):** الموقع https كامل؛ أضفنا فقط `NSAllowsArbitraryLoadsInWebContent`
  كشبكة أمان لمحتوى الويب، وطلبات الإشعارات تمر عبر https أساساً.
- **الجلسة:** نستعمل `WKWebsiteDataStore.default()` الدائم — الولوج يبقى بعد إغلاق التطبيق.
  «الخروج» من الموقع يمسح التوكن من الموقع نفسه، والنبض يتوقف تلقائياً لغياب التوكن.
- **الروابط الخارجية:** قائمة `LSApplicationQueriesSchemes` تضم `whatsapp/maps/geo/itms-apps`
  كي يعمل فحص الروابط قبل فتحها.
- **الأداء:** لا مكتبات خارجية إطلاقاً — كل الملفات من إطارات آبل الرسمية (WebKit،
  UserNotifications، CoreLocation، Network، BackgroundTasks) — حزمة خفيفة جداً ومراجعة سريعة.

## 10) استكشاف الأخطاء

| المشكلة | السبب والحل |
| --- | --- |
| «Failed to register for background updates» في السجل | أعد بناء التطبيق؛ تأكد أن `BGTaskSchedulerPermittedIdentifiers` في Info.plist مطابق تماماً لـ `Config.bgRefreshTaskID` (مطابق مسبقاً في هذه الحزمة) |
| التوقيع يفشل «No profiles for com.aittegrine.center» | غيّر معرّف الحزمة لمعرّف فريد ضمن حسابك، أو أنشئ App ID صريحاً بنفس المعرف |
| لا تظهر الإشعارات | تأكد من ولوجك داخل الموقع أولًا ومن إذن الإشعارات؛ الإشعارات خلفياً تقررها iOS حسب استخدامك للتطبيق |
| ملف الإذن يظهر بالإنجليزية | لغة الجهاز ليست عربية/فرنسية — أضف ترجمة في `Resources/xx.lproj/InfoPlist.strings` وسجّلها في المشروع |
| «Personal team» انتهت صلاحيتها على الجهاز | التثبيت الشخصي صالح 7 أيام — أعد التشغيل من Xcode، أو استعمل TestFlight |

## 11) التوافق مع المرجع

هذه النسخة محاكاة مباشرة لتطبيق أندرويد المعتمد **v1.1.0** (حزمة
`com.aittegrine.center`، نفس الاسم ونفس الألوان ونفس منطق الإشعارات ونفس الرابط
الرسمي `https://centreaitigrine.com` الذي حدده صاحب المركز، بدل رابط Vercel القديم
المدمج في أندرويد — يمكن تغيير الرابط في أندرويد لاحقاً بسطر واحد في Config.java
إن رغبت في توحيد النطاق بين المنصتين).
